# FHG Android — GeckoView + Hiddify VPN Companion (beta)

This is an installable Android project, not a mockup. It is an Android companion to FHG Browser Windows 1.0.0. The source lives in the existing FHG repository under `android/`.

## Implemented and compiled features

- A real Firefox **GeckoView** browser with persistent separate `contextId` cookie/storage partitions for each FHG account.
- Android Keystore AES-256-GCM secret vault stored under app private **no-backup** storage, with atomic writes and explicit failure on decryption/corruption (never silent reset).
- File picker on first run, importing the exact four-line Windows account format: email, password, TOTP Base32 seed, HTTPS Hiddify subscription link.
- Built-in RFC 6238 TOTP display, 30-second countdown, and optional copy.
- Automatic username/password form autofill from the encrypted vault via GeckoView's official `Autocomplete.StorageDelegate`. Password updates are stored automatically on an official ChatGPT/OpenAI login-save event with no extra Save button. Domain matching is strict HTTPS for `chatgpt.com` and `auth.openai.com`; lookalike websites get no credentials. The user, not FHG, clicks Continue and completes provider verification.
- Browser-level **VPN-required** gate and callback closing the Gecko session upon loss of the system VPN. This stops the FHG Gecko browser rather than permitting a direct fallback.
- Hiddify subscription import via the official `hiddify://import/` URL scheme, scoped to installed Android package `app.hiddify.com`. Pressing the button sends the private subscription URL only to the official Hiddify app.
- Open Android VPN settings for the user to select Hiddify as **Always-on VPN** and enable **Block connections without VPN** (system-wide Lockdown/Kill Switch).
- A dashboard with VPN state, encrypted accounts, selected profile, one-tap 2FA, Hiddify import and a ChatGPT browser.

## Essential safety limitation (please read)

**This APK does not embed a full sing-box/VpnService engine.** The VPN tunnel itself is provided by the separately installed official Hiddify Android app, using the same type of subscription as the Windows release. Android ordinarily permits only one active VPN. The FHG in-app browser refuses to load without an active Android VPN and closes on VPN loss; this is a best-effort *browser-level* gate, not a certified OS-wide Kill Switch.

To prevent system-wide direct network access during VPN outage, the **user must enable** Android system VPN settings: `Always-on VPN → Hiddify` and `Block connections without VPN`. Those settings cannot be enabled silently by a normal third-party app. FHG cannot programmatically prove that the user has enabled Lockdown on an unrelated app; its VPN-state indicator only confirms a currently active Android VPN (which could be a different VPN).

No root is required. Do not claim zero DNS/IPv6 leak without actual on-device traffic tests. No network stealth or CAPTCHA bypass is implemented. The user is responsible for account provider login, including any Cloudflare challenge. Browser runtime policies and spoofed `Europe/Berlin` timezone are **not** implemented in this beta; Android platform APIs do not offer a simple equivalent of the desktop signed Firefox extension. TOTP is built into the app rather than the original Firefox desktop add-on. Support for Google/Apple identity-provider popup windows and native passkeys still needs device testing.

## Install and use

1. Install official [Hiddify for Android](https://play.google.com/store/apps/details?id=app.hiddify.com) and the `FHG-Android-0.1.0-beta.apk` generated by the CI release.
2. Open FHG Android; on first launch select the same four-line text config file as on Windows. The encrypted vault is created on-device. The app never uploads the config file.
3. Tap **بازکردن Hiddify** to import the subscription into the official Hiddify app. In Hiddify select and connect a working server, and grant the Android VPN permission.
4. Open **Android Settings → VPN → Hiddify**, enable **Always-on VPN** and **Block connections without VPN** (names vary by vendor).
5. Return to FHG, confirm that a VPN is detected and tap **ورود به ChatGPT**. GeckoView uses the account's isolated cookie jar. The app offers the stored login to official login forms; YOU click Continue / confirm MFA / solve CAPTCHA.
6. Verify real external IP/DNS behavior on your target phone and test Wi-Fi → cellular and disconnect/reconnect scenarios. Do not rely solely on the green connection indicator.

## Build

GitHub Actions workflow: `.github/workflows/fhg-android-apk.yml`. This installs JDK 17, Android SDK API 36 and Gradle 8.13, runs Gradle `:app:assembleDebug`, produces a SHA-256 and publishes a pre-release APK if build tests pass. The APK is Android debug-signed, **not** a Play Store/App Signing production certificate; keep the signing key stable for production updates.

For Android Studio: open `android/`, sync Gradle, build `app` (APK). Requires network access to Google and Mozilla Maven to download GeckoView.

This beta specifically does not replace the existing FHG Windows v1.0.0 release and does not mutate the Windows code.
